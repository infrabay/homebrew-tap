# infrabay Homebrew tap

Homebrew casks for command-line tools published by
[infrabay](https://github.com/infrabay).

```bash
brew install infrabay/tap/peopleforce
```

| Cask | Tool |
| --- | --- |
| `peopleforce` | [peopleforce-cli](https://github.com/infrabay/peopleforce-cli) — CLI for the PeopleForce HR API, built for AI agents and humans |

The casks in `Casks/` are written by each project's release workflow
(GoReleaser) when a version is tagged. Do not edit them by hand: the next
release overwrites them. Report problems in the project's own repository.
